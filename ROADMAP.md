# Izu Tarot Roadmap

## Vision

Izu Tarot is a calm, mystical, reflective tarot web experience.

It is not a deterministic fortune telling app.
It helps users pause, reflect, and understand their current emotional direction.

Core principle:

> Reflect, not predict.
